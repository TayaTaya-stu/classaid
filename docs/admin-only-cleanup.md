# 管理画面だけの整理

## 変更

1. 時間差投影の設定UIを管理画面から外す。
2. 赤い「AIと音声を停止」ボタンを外す。
3. 新しく選べるモードは授業接続・中立・AIなし。共感はUIで新規選択できず、共通設定APIでも保存を拒否する。
4. 「ログ・分析」を「研究用ログ・CSV」に変更し、既定で閉じたdetailsにする。

既に共感が記録されている回は「以前の設定」と表示する。履歴や実験条件は自動で書き換えない。開始前なら別モードへ変更できる。開始後の条件固定は従来どおり。

教授に配布済みの0.1.5はそのまま使う。overlay以下、パッケージ、投影配信ルート、音声、QR、チャット、DB構造はこのパッチでは変更しない。いいね順は追加しない。以前の時間差設定の履歴も削除しない。

## 検証と公開

- node tests/admin-web-cleanup.mjs
- npm run lint
- npm run build
- Webソース3ファイルとテスト・説明書だけを確認してGit/Vercelへ公開。

SQL・環境変数の変更、教授アプリの再ビルド・再配布は不要。

実ソースを使う模擬テストで、共感の設定拒否、中立の設定、開始後の固定、折りたたみ、時間差UIの除去、個別制御の保持を確認。コンテナではlint・TypeScript・Webpackビルドを検証。Windowsの実際の管理画面とVercelへの反映は公開後に確認する。
