# 授業回の整理

- 「準備中・授業中」と「履歴」を切り替えます。終了済みの回は履歴に表示します。非表示にした回は「非表示の回」だけに表示します。一覧は授業日時が新しい順です。今回指定中の回は通常一覧にも残します。
- 「非表示にする」は通常一覧と履歴の両方から授業回を隠す操作です。参加・投稿・AI・音声・研究記録・資料を変更しません。「非表示の回」から「非表示を解除する」で戻せます。準備中の回は通常一覧、終了した回は履歴に戻ります。再開操作ではありません。
- 「未使用の回を削除」は管理画面の通常一覧・履歴・教授アプリから取り除く操作です。変更禁止の作成ログを保持するため、SQL DELETEはしません。内部の授業行・空ルーム・作成ログを保持します。
- 開始・参加・投稿・音声・資料などの記録がある回は削除できません。作成時に自動で記録される `shared_session_created` のみ、未使用判定の対象外です。未知の関連テーブルも外部キーから確認し、記録がある場合は拒否します。
- 授業中・今回指定中の回は整理できません。教授アプリで終了し、別の回を今回使用する回に指定してから整理します。
- 整理は管理者認証必須。DBの整理RPCはservice_roleだけ実行可能です。授業回・ルームをロックし、確認と更新を1トランザクションで実施します。
- SQL 026は列・関数・トリガーを追加するだけです。既存回の整理操作を自動実行しません。SQL 026を先に反映してからWebを公開してください。既存025以前のSQLをまとめて実行する必要はありません。
- 教授アプリの再配布・環境変数変更は不要です。

## 検証

`node tests/session-organization-sql.mjs`

全マイグレーションをローカルPGliteに適用し、未使用回の一覧削除・作成ログ保持・記録のある回の拒否・履歴移動/取り消し・指定中/実施中の保護・未知の外部キー・実行権限を確認します。リモートDBには接続しません。

`node tests/session-organization-web.mjs`

実APIハンドラーとReactコンポーネントをスタブ付きで実行し、認証・削除確認・競合メッセージ・通常/履歴表示・取り除いた回の非表示・確認キャンセル・二重クリック・操作対象ID・履歴30件の外側にある指定回の取得を確認します。実際のブラウザや本番DBの確認は公開後に別途行います。
