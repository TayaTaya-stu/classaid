# 授業コメント投影アプリ（開発版）

共有コメントスクリーンの新着投稿を、PowerPoint・PDF・ブラウザなどの上へ表示するWindows向け透明オーバーレイです。

## 起動

プロジェクト直下で次を実行します。

```powershell
npm run overlay
```

管理画面の「投影画面を開く」で表示される `/screen/…` のURLを入力し、表示先画面を選んで「投影を開始」を押します。

## 動作

- 起動前の過去投稿は表示せず、起動後の新着投稿だけを流します。
- 透明画面はマウス操作を背後へ通すため、スライドを通常どおり操作できます。
- 投影URLなどの設定は、そのPCのElectronユーザーデータ領域だけに保存されます。
- 「テスト表示」で、実際に投稿せず表示位置を確認できます。
- 「QR画面を開く」で既存のブラウザ投影画面を開けます。

授業で使用する際は、Webシステムが教授PCからアクセス可能なURLへデプロイされている必要があります。`localhost` は同じPC内でのテスト専用です。
