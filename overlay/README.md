# SupporTalk 授業投影アプリ（Windows向けオーバーレイ）

SupporTalk の新着投稿およびAI返信を、PowerPoint・PDFスライド・ブラウザなどの上へ透明オーバーレイで流すWindows向け投影アプリです。

## 起動

プロジェクト直下で次を実行します。

```powershell
npm run overlay
```

起動後、「最新の授業を自動検出」を押すか、先生用画面・管理画面の「投影画面URL」を入力し、表示先画面を選んで「投影を開始」を押します。教授画面からの `supportalk://` 連携にも対応しています。

## 動作

- 起動前の過去投稿は表示せず、開始後の新着ペア（人間投稿＋AI返信）を表示します。
- 透明画面はクリック・マウス操作を背後のPowerPointスライドへ透過するため、通常通り授業・スライド操作を行えます。
- 授業開始から120分が経過すると、AI・音声とともに自動停止します。
- 教授画面から「投影のみ停止」「投影再開」を遠隔操作できます。
- 「テスト表示」で、実投影時刻（研究用デモ記録）を保存しつつ表示位置を確認できます。
- 学生入室用QRコードには「標準カメラアプリ利用・LINE非推奨」の案内が常時表示されます。
